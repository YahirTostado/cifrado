# cifrado
Descripción
Aplicación web desarrollada en Angular que permite cifrar y descifrar oraciones utilizando los métodos:
Cifrado César
Cifrado Atbash
El sistema permite al usuario:
Ingresar un texto
Seleccionar el módulo de cifrado
Definir el conjunto de caracteres (ASCII)
Obtener el resultado cifrado o descifrado

En nuestro archivo cifradoSeg/src/app/encriptacion/encriptacion.ts encontramos la logica del cifrado.
